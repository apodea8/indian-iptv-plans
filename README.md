## What does each connection plan actually mean?

The connection number is about **simultaneous viewing**, not the number of devices on which you can install the service.

TiviLive states that one connection supports one simultaneous stream. Two connections support two screens at the same time, and so on.

So the practical difference is simple:

**1 connection:** one active stream at a time.

**2 connections:** useful when two people want to watch different things simultaneously.

**3–5 connections:** designed for households where several screens may be streaming at once.

The nice thing here is that you do not have to solve the entire household puzzle on day one. You can test the service first, then match the connection count to actual usage rather than guessing.
